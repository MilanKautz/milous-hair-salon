# Milou's Hair Salon website

## Starten

Dubbelklik op `start-lokaal.cmd`. De website opent daarna op `http://localhost:8080`.

## Pagina's

- `index.html` — landingspagina met salonintroductie en diensten.
- `salon.html` — salonfoto's en de visie achter de inrichting.
- `reserveren.html` — interactieve reserveringsdemo.

De reservering is een demo; echte afspraken vereisen een database, beveiligde beheeromgeving, beschikbaarheidscontrole, e-mailconfiguratie en AVG-maatregelen.
